# 舆策 · SENTRA

### 舆情研判与短线策略系统

SENTRA 是一个面向股票短线分析场景的智能策略 Demo。

![SENTRA 舆情研判与短线策略大屏](首页.jpg)

系统从**财经资讯、股吧舆情、实时行情、资金流向**等多源数据中提取市场信息，通过规则分析和大模型 API 两种方式进行综合研判，并进一步生成 5 日短线策略。

项目重点不是直接预测股票未来价格，而是将分散的市场信息进行结构化整合，通过 **“数据 → 分析 → 研判 → 策略 → 风险校验”** 的完整流程，为用户提供辅助决策信息。

> **核心理念：让分散的市场信息，最终转化为结构化、可解释的短线策略。**

## 核心功能

### 1. 多源市场数据采集

系统支持从多个数据源获取市场信息：

| 数据类型 | 数据来源       | 主要内容                  |
| ---- | ---------- | --------------------- |
| 股吧舆情 | 东方财富股吧     | 热门话题、正文、阅读量、评论数、关联股票  |
| 财经资讯 | 东方财富财经时评   | 新闻标题、正文、发布时间          |
| 行情数据 | 东方财富公开页面接口 | 最新价、涨跌幅、成交额、换手率、5日波动率 |
| 资金数据 | 东方财富公开页面接口 | 主力资金净流入、行业资金分布        |

支持**定时采集和手动触发**两种方式，并对采集任务设置运行间隔和失败重试机制。

---

### 2. 行业与舆情分析

系统对采集到的市场信息进行结构化分析，包括：

* 股吧话题热度分析
* 行业关联关系分析
* 行业情绪评分
* 政策与新闻信息整理
* 行业资金流向分析
* 行业综合评分
* 热点行业识别
* 股票候选池构建

最终形成从：

**市场热点 → 行业 → 个股**

的分析链路。

---

### 3. 规则 / AI 双研判引擎

SENTRA 支持两种研判方式。

#### 规则模式

无需外部大模型 API。

根据系统已有的：

* 市场热度
* 行业情绪
* 政策信息
* 资金趋势
* 行情表现
* 综合评分

进行规则化综合判断。

特点：

* 无需 API Key
* 结果稳定
* 可重复运行
* 方便本地 Demo 和测试

#### AI API 模式

接入兼容 OpenAI API 的大模型。

将经过结构化处理的市场信息交给大模型进行综合研判，输出：

* 当前市场状态
* 主线行业
* 综合判断
* 判断依据
* 机会点
* 风险点
* 策略倾向

AI主要负责**多源信息综合分析与策略生成**，而不是直接预测股票未来价格。

---

### 4. AI 辅助策略生成

在综合研判结果基础上生成 5 日短线策略。

策略包含：

* 关注股票
* 策略倾向
* 当前价格
* 关注区间
* 目标区间
* 入场条件
* 止盈条件
* 风险控制
* 主要风险
* 策略理由

系统同时保留规则层的策略约束，对 AI 生成结果进行可执行性检查。

例如：

```text
AI综合判断
    ↓
AI生成策略
    ↓
预算检查
    ↓
仓位检查
    ↓
价格区间检查
    ↓
风险条件检查
    ↓
最终策略
```

这样可以避免完全依赖大模型自由生成交易参数。

---

### 5. 真实行情 / 模拟数据切换

系统支持两种市场数据模式：

**模拟模式**

用于：

* 本地开发
* Demo 演示
* 流程测试
* 结果回放

**真实模式**

可以手动获取东方财富公开页面中的实时行情和资金数据，并将其应用到策略工作流。

两种模式可以在系统中切换，不影响基础分析流程。

## API

主要接口：

| 接口                              | 方法   | 说明         |
| ------------------------------- | ---- | ---------- |
| `/api/health`                   | GET  | 系统健康检查     |
| `/api/workflow/latest`          | GET  | 获取最新完整研判结果 |
| `/api/workflow/run`             | POST | 执行完整分析流程   |
| `/api/workflow/node/{node_id}`  | POST | 重跑指定分析节点   |
| `/api/market-data/fetch`        | POST | 获取行情和资金数据  |
| `/api/workflow/apply-real-data` | POST | 应用真实行情     |
| `/api/workflow/reset-simulated` | POST | 切回模拟模式     |
| `/api/admin/overview`           | GET  | 获取系统运行总览   |
| `/api/scheduler/enable`         | POST | 启用定时任务     |
| `/api/scheduler/disable`        | POST | 停止定时任务     |

## AI API 配置

项目支持兼容 OpenAI API 的模型服务。

建议通过环境变量配置 API 信息，不要将 API Key 直接写入代码或提交到 GitHub。

示例：

```env
OPENAI_API_KEY=your_api_key
OPENAI_BASE_URL=your_base_url
OPENAI_MODEL=your_model
```

如果没有配置 API Key，可以直接使用**规则模式**运行完整流程。

## 项目特点

### 1. 从“数据展示”到“策略输出”

不是简单展示新闻、情绪和资金数据，而是将多源数据进一步整合：

```text
数据
↓
分析
↓
综合研判
↓
策略生成
↓
风险校验
```

形成完整的业务闭环。

### 2. AI 与规则结合

AI负责：

> **综合信息、解释判断、生成策略**

规则负责：

> **数据计算、交易约束、策略校验**

降低完全依赖大模型生成结果带来的不确定性。

### 3. 真实数据与模拟数据兼容

既支持本地 Demo 和流程回放，也支持接入真实行情进行展示。

### 4. 工作流可追踪

每个主要分析节点都有执行状态和日志，便于定位数据采集、分析和策略生成过程中的问题。
